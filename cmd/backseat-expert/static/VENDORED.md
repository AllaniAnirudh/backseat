# Vendored third-party assets

`xterm.js` and `xterm.css` are the upstream prebuilt bundles of the
[xterm.js](https://github.com/xtermjs/xterm.js) terminal emulator library
(MIT, see `LICENSE.xterm`). They are vendored here so the expert web UI works
offline without a CDN. They are not project source and were not written or
modified by this repository's authors.
